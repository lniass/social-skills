# social-skills

Reusable public skill pack for the Social Agent experience.

This repo is for agent behavior: what the agent asks, says, drafts, and enforces during onboarding/content workflows.

It complements `social-agent-orchestrator`:

- `social-agent-orchestrator`: hosted API, state machine, Supabase persistence, Social Connect proof, scheduling/usage gates.
- `social-skills`: user-facing workflow instructions, onboarding scripts, content rules, approval behavior, platform-specific guidance.

## Current MVP skill packs

- `skills/facebook-first-public-onboarding/SKILL.md`

Public MVP supports Facebook Pages first. More platforms can be added as separate skills later.
